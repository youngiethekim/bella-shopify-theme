# Bella — Shopify Theme

Custom Online Store 2.0 theme for Bella Virtual Staging, built from the
[bella-preview](https://github.com/youngiethekim/bella-preview) design mockups.

Connected to Shopify via the GitHub integration: pushes to `main` update the
theme automatically, and changes made in the Shopify theme editor are committed
back to this repo by Shopify.

- `sections/bella-*` — homepage + service-page sections
- `sections/main-*` — product / collection / cart / blog / search templates
- `templates/page.lookbook.json` — the furniture lookbook page template
- `assets/bella.css` / `bella.js` — ported styles and interactions
